# 🔍 Python Port Scanner

A lightweight, fast, and simple command-line TCP port scanner built with Python. 

This tool is designed to check common network ports (like HTTP, HTTPS, SSH, FTP) to see if they are open on a specific target IP or domain. It's a great foundational project for understanding networking and cybersecurity basics.

## ✨ Features
- **Fast Scanning**: Uses Python's native `socket` library.
- **No Dependencies**: Runs on standard Python 3 (no `pip install` required).
- **Error Handling**: Gracefully handles incorrect hostnames and manual interruptions.
